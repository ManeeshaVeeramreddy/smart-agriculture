Smart Agriculture Monitoring System

A full-stack, layered architecture web platform empowering farmers to manage fields, track crops, record agricultural conditions, receive automated irrigation alerts, and obtain rule-based crop suitability recommendations.

🌱

Field & Crop Management

Maintain parcel locations, acreage, soil classifications (Loamy, Clay, Sandy), and track crop lifecycle statuses from sowing to harvest.

💧

Automated Irrigation Logic

Spring Boot Service Layer evaluates soil moisture against the 30% threshold: Soil Moisture < 30% triggers Irrigation Required and automatic alert dispatch.

🚨

Proactive Alert Generation

Receive instant notifications when critical dryness is detected, with dedicated active and historical alert tracking.

📊

Rule-Based Crop Recommendations

Determines crop suitability scores (Rice, Wheat, Maize, Tomato, Groundnut) based on temperature, humidity, moisture, and soil compatibility.
